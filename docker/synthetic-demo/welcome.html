Try the four teaching modules

  1. Sign in as demo.teacher.
  2. Schemes of Work: view DEMO - Temperature scheme, then select Generate weekly plans (AI).
  3. Lesson Plans: view DEMO - Temperature lesson, then select Curriculum AI draft.
  4. Homework: view DEMO - Temperature homework, then select Curriculum AI draft.
  5. Exam Papers: open DEMO - Temperature paper, then select Curriculum AI draft.
  6. The demo preselects Grade 7 and the original temperature-reading unit. Click Generate draft, inspect/edit the JSON, then use the explicit Import or Apply button.
  7. Inspect the saved weeks, lesson sections, questions and marking guidance. All documents remain drafts until you deliberately use their normal workflow actions.

The initial sample documents start ready for your imports. After importing, use manual edits or create another homework/paper to repeat the exercise. Existing scheme weeks and question duplicates are protected.
